Family members

Family groups

Groups are how you give access. Put each approved member into one or more groups, then choose which groups can open each section.

Sections with documents

Each section is a page of documents, such as the Pujo and Bhog accounts. New sections start as admin only.

Events

Each event gets a photo wall and, if you tick it, a Nirghonto page. Add next year's Pujo or any other occasion here.

Social links

Removing a section or event hides its page. The photos and documents in it stay stored and come back if you add it again with the same title.

Backup

The backup is one zip file with everything on the site: orders, members, posts, schedules, photos and documents. Download one after any important change and keep it on your computer or Google Drive.
